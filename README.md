# Marvel Superhero Network

This folder contains a GitHub Pages-ready static site for the Social Graphs
week 1 project.

## Publish with GitHub Pages

1. Create a GitHub repository and copy the contents of this folder into it.
2. Push the files to the repository's default branch.
3. In **Settings → Pages**, choose **Deploy from a branch**, select the default
   branch and the `/ (root)` folder, then save.
4. GitHub will provide the published site URL.

The site already includes a home page and a week 1 analysis page. The analysis
page is intentionally a placeholder until the community calculations and
figures are added.
